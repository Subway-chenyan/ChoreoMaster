## 1. 你会用到的核心概念

- 项目
  - 桌面端：项目存储在本机目录，可在应用内创建/打开/重命名/复制/删除。
  - 网页端：不提供“本地项目库”，可通过“教学示例”快速体验，并用导入/导出 JSON 进行保存与迁移。
- 队形（时间轴帧）
  - 每个队形包含：名称、起始时间、持续时间、以及“当前队形里出现的演员/道具”的位置数据。
  - 同一个演员/道具可以在某些队形里出现、在另一些队形里不出现。
- 演员 / 道具
  - 演员与道具都在舞台上以“可拖动的图标”呈现。
  - 道具支持分类（例如：普通道具 / 高台），高台会影响演员抬升逻辑（用于 3D 与导出）。
- 分组
  - 用于组织演员/道具列表。
  - 支持在“当前队形”隐藏/显示某个分组（只影响当前队形的显示与编辑）。
- 舞台设置
  - 舞台宽度、深度、左右备场区宽度、LED 屏幕宽高与内容等。
- 配乐
  - 导入音频后，时间轴会显示波形；播放/导出会按时间线与配乐对齐。

## 2. 快速上手（建议顺序）

### 2.1 桌面端（Electron）

1. 左侧切到“项目”页
2. 点击“新建项目”并命名
3. 在“配乐”区域点击“导入音频文件”
4. 在“演员”页点击“添加演员”（或在“道具”页添加道具）
5. 在舞台中选择演员并拖拽到需要的位置
6. 在时间轴点击“添加”创建更多队形，拖拽帧块调整队形出现时间/时长
7. 按 Space 播放预览；需要时点击“导出视频”
8. 保存：点击“保存项目”或按 Ctrl/⌘ + S

### 2.2 网页端（Web）

1. 左侧“项目”页使用“教学示例”快速体验
2. 需要保存/迁移时使用“导出 JSON / 导入 JSON”
3. 其它编辑逻辑（舞台/时间轴/导出视频）与桌面端一致

## 3. 项目管理（桌面端）

### 3.1 本地项目库

- 入口：左侧“项目”页的“本地项目”
- 新建：点击“新建项目”
- 打开：点击项目卡片
- 右键项目卡片或点击卡片右侧菜单：
  - 重命名
  - 复制项目
  - 在文件夹中显示
  - 删除项目（不可撤销）

### 3.2 导入/导出项目包（桌面端）

- 导入项目包：点击“导入项目包”
- 导入旧 JSON：点击“导入旧 JSON”
- 导出项目包：点击“导出项目包”
  - 若当前项目有未保存更改，会先尝试保存再导出

### 3.3 导入/导出 JSON（桌面端与网页端都可）

- 导出 JSON：导出当前编排（演员、队形、舞台设置等）为 JSON 文件
- 导入 JSON：载入 JSON 文件恢复编排
  - 注意：导入 JSON 后通常需要重新导入音频文件（音频文件本身不会内嵌到 JSON 中）

## 4. 舞台编辑（演员/道具摆位）

### 4.1 选择与多选

- 单击某个演员/道具：选中它
- Ctrl/⌘ + 单击：对选中状态进行“添加/取消”（多选）
- 框选：在舞台空白处按住拖拽形成矩形框，松开后选中框内对象
  - 按住 Ctrl/⌘/Shift 再框选：会与当前选中集合合并

### 4.2 移动与对齐

- 拖拽选中的演员/道具：移动位置
- 多选状态下拖拽任意一个选中对象：整组选中对象一起移动

### 4.3 当前队形中“出现/消失”

演员/道具是否“在当前队形出现”，取决于该队形是否包含它的位置数据：

- 通过列表切换：在左侧演员/道具列表中，点击对象右侧的“添加到此队形 / 从此队形移除”按钮
- 通过删除快捷键：
  - 当你选中了演员/道具时，按 Delete/Backspace 会把它们从“当前队形”移除（不会删除对象本身）
- 全局删除（不会只影响当前队形）：
  - 在左侧演员/道具列表中，点击对象右侧的“全局删除”垃圾桶图标，会把该对象从项目中彻底删除（会影响所有队形）

### 4.4 网格缩放（密度）

- 鼠标滚轮：缩放 2D 舞台视图
- Ctrl + 鼠标右键拖拽：平移整个 2D 舞台画布
- Ctrl + 鼠标滚轮：调整舞台网格缩放
- 也可以通过界面上的缩放按钮（显示为 x1.0、x1.5 等）进行调整

## 5. 时间轴与队形编辑

### 5.1 播放与定位

- Space：播放 / 暂停
- 拖拽时间轴空白区域：快速定位播放头（Scrub）
- 单击某个队形帧块：选中队形（当没有选中演员/道具时）

### 5.2 新增队形

- 时间轴工具栏点击“添加”
  - 会在当前时间创建一个新的队形

### 5.3 调整队形时间与时长

- 拖拽队形帧块：移动队形在时间轴上的位置（改变 startTime）
- 拖拽队形帧块右侧把手：改变队形时长（duration）

### 5.4 重命名队形

- 双击队形帧块进入编辑
- Enter：确认
- Escape：取消

### 5.5 复制/粘贴与删除（区分“演员/道具”与“队形”）

同一组快捷键会根据“当前是否选中了演员/道具”而触发不同对象的操作：

- Ctrl/⌘ + C / Ctrl/⌘ + V
  - 有选中演员/道具：复制/粘贴演员（仅当前队形相关的摆位）
  - 没有选中演员/道具：复制/粘贴队形（帧）
- Delete / Backspace
  - 有选中演员/道具：从当前队形移除这些对象
  - 没有选中演员/道具：删除当前选中的队形帧

## 6. 分组（演员/道具管理）

- 创建分组：在“演员”或“道具”页，打开“创建分组”，输入名称与颜色并创建
- 折叠/展开：点击分组左侧箭头
- 重命名分组：双击分组名称；Enter 确认，Escape 取消
- 拖拽分组：把演员/道具从列表中拖到分组标题区域即可加入
- 从分组移出：把对象拖到“未分组”区域
- 隐藏/显示分组（当前队形）：点击分组右侧“眼睛”图标

## 7. 舞台设置（配乐 / 尺寸 / LED）

### 7.1 配乐（音频）

- 入口：左侧“项目”页 → “配乐” → “导入音频文件”
- 桌面端：音频会复制到当前项目资源目录，保存项目后可随项目包一起迁移
- 网页端：音频只在当前浏览器会话可用，刷新页面需要重新导入

### 7.2 LED 屏幕背景（图片/视频）

- 入口：左侧“项目”页 → “LED 屏幕内容” → “上传图片/视频”
- 支持图片或视频作为 LED 屏幕材质
- “清除”按钮会移除当前 LED 内容设置

## 8. 导出视频（2D / 3D）

### 8.1 打开导出设置

- 入口：时间轴工具栏右侧“导出视频”

### 8.2 设置导出时间范围（入点/出点）

导出会使用“入点/出点”作为时间范围：

1. 先把播放头移动到导出开始位置
2. 打开导出设置，在“入点（秒）”点击“当前”（或直接输入秒数）
3. 把播放头移动到导出结束位置
4. 在“出点（秒）”点击“当前”（或直接输入秒数）

### 8.3 选择输出类型与参数

- 输出类型：2D、3D 可同时勾选
- 显示姓名：控制导出时是否渲染演员/道具名称
- 显示网格：控制导出时是否显示网格线
- 分辨率：1080p / 2K / 4K
- 3D 机位：评委视角 / 45°俯视（仅勾选 3D 时可选）

### 8.4 导出进度与常见注意事项

- 导出过程中时间轴工具栏会显示进度条与录制进度
- 导出较长时间段或高分辨率（2K/4K）对设备性能要求更高
- 若浏览器不支持 WebCodecs，可能会回退到 WebM 录制方式（文件体积与清晰度会有差异）

## 9. 快捷键总表

### 9.1 全局快捷键

- 播放 / 暂停：Space
- 保存项目（桌面端）：Ctrl/⌘ + S
- 撤销：Ctrl/⌘ + Z
- 重做：Ctrl/⌘ + Y 或 Ctrl/⌘ + Shift + Z
- 帮助：F1 或 Ctrl + /

### 9.2 与选择状态相关的快捷键

- 删除：Delete / Backspace
  - 有选中演员/道具：从当前队形移除
  - 未选中演员/道具：删除当前队形帧
- 复制 / 粘贴：Ctrl/⌘ + C / Ctrl/⌘ + V
  - 有选中演员/道具：复制/粘贴演员
  - 未选中演员/道具：复制/粘贴队形帧
