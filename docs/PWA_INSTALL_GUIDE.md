# ChoreoMaster 手机端 PWA 安装指南

## 什么是 PWA？

PWA（Progressive Web App）是一种可以像原生 App 一样安装到手机主屏幕的网页应用。安装后可以全屏使用，体验接近原生 App。

## 安装步骤

### Android（Chrome 浏览器）

1. 用 Chrome 浏览器打开 ChoreoMaster 网站
2. 点击浏览器右上角的 **⋮**（三点菜单）
3. 选择 **"添加到主屏幕"** 或 **"安装应用"**
4. 确认安装，应用图标会出现在主屏幕上
5. 点击图标即可全屏使用

### iPhone / iPad（Safari 浏览器）

1. 用 **Safari** 浏览器打开 ChoreoMaster 网站
   > ⚠️ 必须使用 Safari，Chrome 等其他浏览器不支持 iOS 安装 PWA
2. 点击底部的 **分享按钮**（方框+向上箭头图标）
3. 向下滚动，找到 **"添加到主屏幕"**
4. 可以修改显示名称，然后点击右上角 **"添加"**
5. 回到主屏幕，点击 ChoreoMaster 图标即可使用

### 应用内安装

部分浏览器支持在页面内直接安装：

- 打开 ChoreoMaster 后，如果浏览器支持，顶部栏会出现一个 **"安装"** 按钮（📥 下载图标）
- 点击该按钮即可快速安装

## 常见问题

### Q: 安装后打开是空白页面？
**A:** 请确保手机有网络连接。PWA 首次打开需要联网加载资源，之后部分内容可以离线使用。

### Q: 安装后界面不是手机适配的？
**A:** 如果安装后显示的是电脑版界面，请尝试：
1. 完全关闭应用（从后台划掉）
2. 重新打开应用
3. 如果仍然有问题，清除浏览器缓存后重新安装

### Q: 如何更新 PWA？
**A:** PWA 会自动检测更新。如果有新版本，重新打开应用时会自动加载最新版本。也可以手动清除浏览器缓存来强制更新。

### Q: 支持哪些手机？
**A:**
- **Android 5.0+**：Chrome 67+ 或其他 Chromium 内核浏览器
- **iOS 16.4+**：Safari 浏览器（iOS 16.4 开始支持完整 PWA 功能）

### Q: 安装后可以离线使用吗？
**A:** 部分功能可以离线使用（如查看已保存的项目），但 AI Agent、音乐播放等需要网络的功能仍需联网。

## 技术说明

- PWA 使用 Service Worker 缓存应用资源，提升加载速度
- 支持 `standalone` 显示模式，隐藏浏览器地址栏
- 适配刘海屏、挖孔屏等异形屏幕（`viewport-fit=cover`）
- 触控目标最小 44px，符合无障碍访问标准
