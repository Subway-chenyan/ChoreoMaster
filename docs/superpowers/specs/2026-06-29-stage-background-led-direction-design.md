# 舞台底图、LED 纵深与对象朝向设计

## 目标

为舞台编辑器补充三组一致贯穿实时编辑和导出的能力：

1. 上传舞台底图，按图片比例建立真实舞台尺寸，并调节底图透明度。
2. 自定义 LED 距舞台后沿的位置，为 LED 后方保留串场区域。
3. 恢复演员旋转交互，并为演员、道具提供始终可见的朝向箭头。

## 已确认的交互规则

### 舞台底图

- 底图覆盖整个可用舞台，即主舞台与左右备台的总区域。
- 上传图片后弹出尺寸确认界面，用户输入图片对应的真实总宽度（米）。
- 系统根据图片像素宽高比计算舞台深度：`深度 = 真实总宽 × 图片像素高度 / 图片像素宽度`。
- 主舞台宽度由总宽扣除两侧备台得到：`主舞台宽度 = 真实总宽 - 2 × 单侧备台宽度`。
- 当输入总宽不大于两侧备台总宽时阻止确认，并提示用户增大总宽或先减小备台宽度。
- 图片完整铺满舞台，不裁切；由于舞台宽深比同步图片比例，因此不会发生形变。
- 宽深比在上传或替换底图时同步一次；之后用户仍可独立修改舞台尺寸，系统不持续锁定比例。
- 支持调节透明度和清除底图。
- 底图在 2D、实时 3D、2D 导出和 3D 导出中显示；3D 中作为地面纹理。

### 舞台划线

- 提供一个“舞台划线”总开关。
- 关闭时隐藏两侧备台边界线和横向分割线；舞台实体、底图、对象及必要的前后方向标识不受影响。
- 新项目和旧项目默认开启。

### LED 位置

- 新增“LED 距舞台后沿”数值，单位为米。
- `0m` 表示 LED 贴近舞台后沿；数值增大时 LED 向舞台前方移动，后方形成串场区。
- 数值限制在 `0..舞台深度` 的有效范围内；舞台深度缩小时自动钳制显示和渲染值。
- 实时 3D 与离线 3D 导出的 LED 使用相同位置计算。
- 2D 舞台显示 LED 所在横向位置线，便于排布演员和道具。

### 旋转与朝向箭头

- 演员恢复与道具一致的旋转拖柄，可在当前关键帧修改角度，并进入既有撤销/重做与帧间旋转插值链路。
- 演员和道具的朝向箭头始终显示；箭头尖端代表对象正面。
- 2D 箭头跟随对象角度旋转，但保持足够对比度和小尺寸，避免遮挡名称及缩放手柄。
- 3D 演员与道具均增加随对象旋转的地面/实体朝向箭头。
- 实时 3D 和离线 3D 导出使用同一朝向约定，确保正负角方向一致。

## 数据模型

在 `StageConfig` 中新增可选字段，保持旧项目兼容：

- `background?: { value: string; opacity: number; pixelWidth: number; pixelHeight: number }`
- `showStageLines?: boolean`
- `ledDistanceFromBack?: number`

底图文件沿用项目资源导入与持久化机制。`value` 在 Web 环境可为 data URL，在 Electron 项目中可为已导入资源对应的可加载 URL；保存、另存、导入和清理行为与现有 LED 图片资源保持一致，但使用独立资源类别，避免误清理 LED 内容。

默认值：无底图、透明度 `0.5`、舞台划线开启、LED 距后沿 `0`。

## 组件与渲染边界

### 配置与上传

- `App.tsx` 负责选择文件、读取图片固有尺寸、弹出真实总宽确认、更新 `StageConfig` 以及项目资源生命周期。
- `Sidebar.tsx` 提供上传/替换、清除、透明度、舞台划线和 LED 距后沿控件。
- 尺寸换算提取为纯函数，供界面逻辑和单元测试复用。

### 2D

- `Stage.tsx` 在所有网格、边界、路径和对象的下方渲染底图。
- 底图以 `100% × 100%` 覆盖舞台画布，透明度来自配置。
- 舞台划线开关控制备台边界和横向分割线。
- LED 位置以不抢占对象交互的只读横线表示。
- 演员容器应用当前帧旋转，并复用现有旋转开始、变化、结束回调；演员与道具分别渲染统一语义的箭头。

### 实时 3D

- `StageFloor.tsx` 接收舞台配置并为地面材质加载底图纹理；透明度与 2D 一致。
- `LEDTV.tsx` 根据 LED 距后沿值调整纵深坐标。
- `Performer3D.tsx` 与 `Prop3D.tsx` 增加朝向箭头几何体，作为对象组的一部分随角度旋转。

### 离线导出

- `OfflineRenderer3D.ts` 加载底图纹理、复用 LED 位置公式，并为演员和道具生成朝向箭头。
- 2D 导出使用与 `Stage.tsx` 相同的舞台底图、划线开关、LED 位置线和对象箭头规则。
- 图片资源预加载失败时继续导出基础舞台，并报告可理解的警告，不让整个导出崩溃。

## 错误处理

- 拒绝非图片文件、无法解码的图片、零尺寸图片及非法真实宽度。
- 上传确认取消时不改变现有底图和舞台尺寸。
- 更换底图成功后才释放旧资源；失败时保留旧底图。
- 透明度钳制为 `0..1`；LED 距后沿钳制为 `0..舞台深度`。
- 旧项目缺少新字段时通过渲染默认值兼容，不强制迁移文件。

## 验收与测试

- 单元测试尺寸换算、非法总宽、透明度与 LED 距离钳制。
- 项目契约测试覆盖新增字段保存/加载及旧项目兼容。
- 组件/构建验证覆盖演员旋转回调重新启用，以及所有新增属性在 2D、3D 链路中的类型传递。
- 手工验证上传示例场地图后：舞台宽深比与图片一致；透明度生效；划线可隐藏；LED 前移后后方留白；演员与道具在 2D、3D 中的箭头方向一致。
- 导出验证 2D 与 3D 视频/截图均包含底图和箭头，且 LED 位置与实时预览一致。

## 非目标

- 本次不支持底图裁切、旋转、透视校正或多个底图图层。
- 本次不改变演员和道具现有坐标百分比模型。
- 本次不增加 LED 横向偏移或旋转。
