# 过渡路径编辑与道具铰链旋转设计

## 目标

在选中过渡时，让用户直接在舞台上查看并编辑所有演员与道具的运动轨迹；普通道具支持中心、左轴和右轴旋转，并可在移动过程中同步旋转。队形角度、实时预览、2D/3D 导出和项目持久化保持一致。

## 交互设计

1. 点击时间轴过渡后，舞台显示该段所有前后队形均存在对象的轨迹。
2. 当前对象轨迹高亮并显示 Bezier 控制点；其他轨迹以对象颜色低透明度显示。
3. 点击舞台对象、轨迹或紧凑对象列表均可切换当前对象。
4. 对象列表展示对象名称、演员/道具类型、路径状态和旋转状态。
5. 普通道具显示旋转手柄与角度数值输入；高台固定中心轴。
6. 播放头位于队形区时修改当前队形角度；位于过渡区时修改目标队形角度。
7. 旋转拖动结束后记录一次撤销操作。

## 数据模型

- `Frame.rotations?: Record<string, number>`：保存该队形逐对象角度。
- `Performer.rotationPivot?: 'center' | 'left' | 'right'`：普通道具旋转轴；旧项目默认 `center`。
- `ObjectMotion.startRotation/endRotation` 继续作为过渡显式覆盖；未设置时使用前后帧角度。

位置语义：

- `center`：帧位置与路径表示几何中心。
- `left | right`：帧位置与路径表示道具局部左/右铰链点。

## 轴切换迁移

切换旋转轴时，根据道具尺寸和每个队形角度，将所有帧位置从旧轴坐标换算到新轴坐标，使几何中心保持不变。相关过渡的 Bezier 控制点使用对应端点角度插值进行换算，使轨迹视觉形状不跳变。

## 渲染与求值

共享场景求值器输出 `positions` 与 `rotations`：

- 静态队形读取 `frame.rotations`，缺失时回退 `performer.rotation`。
- 过渡默认在前后帧角度间插值。
- 2D 舞台、3D 场景、Canvas 导出和离线 3D 均应用相同 pivot 几何换算。

## 兼容与边界

- 旧项目没有 `rotations` 或 `rotationPivot` 时保持原行为。
- 高台强制中心轴，演员承载与抬升逻辑不变。
- MVP 仅支持直线和三次 Bezier，不包含自由手绘、碰撞避让或批量路径编辑。

## 验证

- 单元测试覆盖帧角度插值、pivot 坐标换算与轴切换迁移。
- 项目服务测试覆盖新字段持久化和旧项目默认值。
- 浏览器验证覆盖多轨迹显示、对象切换、控制点拖动、旋转手柄和数值输入。
- 构建验证覆盖 Electron 主进程、Vite、2D/3D 导出代码路径。
