# 跨项目复制演员与队形

## Goal

让演员和队形剪贴板可以跨项目工作：框选演员后复制，切换项目再粘贴时恢复复制瞬间的坐标与显示状态；复制整个队形时，在目标项目创建外观、道具属性、贴图和坐标一致的对象。

## What I already know

- 当前演员剪贴板把位置保存为 `sourceFrameId -> Position`，粘贴时却按目标项目的 frame ID 查找；跨项目 ID 不同，因此没有任何位置写入，新对象表现为坐标回退且隐藏。
- 当前队形剪贴板只保存 `Frame`，没有保存该帧引用的演员、道具、分组和贴图数据；跨项目粘贴只能创建带旧对象 ID 的空壳队形。
- 当前演员粘贴无条件给名字添加 `(Copy)`；用户要求跨项目队形粘贴保留原名，不添加后缀。
- 项目贴图可能是 `data:` URL，也可能是指向源项目资源的 `choreo-asset:` URL；跨项目长期保存需要把剪贴板变成自包含资源，而不能保留源项目相对路径。

## Assumptions (temporary)

- 跨项目粘贴始终创建新的演员/道具 ID，不复用目标项目中的同名对象。
- 复制坐标以执行复制命令时的当前队形为准，而不是尝试按不同项目的 frame ID 对齐全部时间轴。

## Open Questions

- 无。

## Requirements (evolving)

- 框选或多选演员后复制，粘贴到任意项目时使用复制瞬间当前队形的坐标。
- 演员粘贴后默认可见，不再因为目标 frame ID 不同而丢失位置。
- 队形剪贴板携带源项目全部演员、道具、相关分组、道具几何、旋转、贴图和帧状态，包括当前队形隐藏的对象。
- 队形跨项目粘贴创建新对象并重映射全部对象 ID。
- 跨项目队形粘贴保留原始对象名称，不添加 `Copy` 后缀。
- 贴图必须随剪贴板迁移，目标项目保存并重启后仍可正常显示。
- 整个队形粘贴时，源队形隐藏的对象在目标队形中继续隐藏；它们仍会出现在目标项目的演员/道具列表中。

## Acceptance Criteria (evolving)

- [ ] 在项目 A 框选多个演员复制，切换项目 B 后粘贴，演员立即在当前队形的原坐标显示。
- [ ] 单项目内粘贴也恢复复制时当前队形坐标，不归零、不隐藏。
- [ ] 复制项目 A 的队形并粘贴到项目 B 后，目标项目出现对应的新演员、道具和队形。
- [ ] 源项目全部演员和道具均被创建，包括复制队形中没有坐标或因分组设置而隐藏的对象。
- [ ] 新对象的名称、颜色、形状、尺寸、道具属性和贴图与源项目一致。
- [ ] 新队形的位置、旋转和舞台坐标与源队形一致。
- [ ] 保存并重新打开项目 B 后，跨项目复制的贴图仍可显示。
- [ ] 原有撤销/重做、同项目复制和项目保存测试通过。

## Definition of Done

- 测试先复现 frame ID 不匹配和队形对象缺失，再实现修复。
- 新剪贴板数据结构有独立、可测试的 ID 重映射逻辑。
- TypeScript、桌面回归和生产构建通过。
- 更新帮助文案与相关 Trellis 规范。

## Technical Approach

引入两种明确的应用内剪贴板载荷。演员载荷保存所选对象、相关分组以及复制瞬间从场景求值结果取得的坐标和旋转；粘贴时在目标当前队形创建新 ID，并无条件写入位置以保证默认显示。队形载荷保存源项目全部演员、道具、分组和当前 `Frame`；粘贴时创建完整 ID 映射，重写对象绑定、分组、位置、旋转和隐藏分组 ID，再创建目标队形。

复制操作异步解析贴图：保留 `data:` 内容；将 `choreo-asset:` 或其他可读取 URL 转换为 data URL；清除源项目相对 `assetPath`。这样目标项目下一次保存时会按既有项目服务把贴图写入自己的资源目录。

## Decision (ADR-lite)

**Context**: 现有演员位置以源 frame ID 为键，跨项目无法匹配；现有队形剪贴板只保存 Frame，缺少对象定义和资源。

**Options**:

1. 自包含内存快照：复制时读取并内嵌资源。
2. 粘贴时通过 IPC 从源项目复制资源文件。
3. 复用目标项目同名对象，仅迁移坐标。

**Decision**: 采用自包含内存快照。它不依赖源项目继续存在或存储路径不变，也能在 Web 与 Electron renderer 复用同一映射逻辑。

**Consequences**: 复制含大量贴图的项目会占用更多内存，复制命令需要异步完成；剪贴板只保留在当前应用会话中。

## Out of Scope (explicit)

- 操作系统级剪贴板以及关闭应用后的剪贴板持久化。
- 跨设备复制。
- 同步音乐、音频标记、舞台尺寸或整个项目设置。
