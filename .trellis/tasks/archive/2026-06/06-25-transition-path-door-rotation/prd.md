# 过渡路径编辑与门板旋转

## Goal

让用户能直接在舞台上快速选择并编辑当前过渡中每个演员或道具的运动路径，同时一眼看到所有对象的轨迹；门板道具在移动过程中可同步旋转，并确保 2D、3D、播放和导出结果一致。

## What I already know

- 用户选择“舞台直接编辑”为主交互，并补充小型对象列表用于快速切换。
- 选中一个过渡时，舞台显示该过渡中所有对象的运动轨迹。
- 当前选中对象的轨迹和控制点突出显示，其他对象轨迹作为上下文弱化显示。
- 点击舞台对象或对象列表项都可切换当前路径编辑对象。
- 普通道具需要支持移动和旋转同时发生，门板是主要使用场景。
- 每个普通道具可选择旋转轴：中心、左轴或右轴。
- 左轴和右轴相对于门板自身局部方向定义，旋转轴点随门板移动。
- 使用左轴或右轴时，队形位置与过渡路径位置均表示铰链轴点，而非道具几何中心。
- 切换 `center | left | right` 时，自动换算该道具在所有队形中的位置，使几何体视觉位置保持不变。
- 切换旋转轴时，同步换算该道具已有过渡的 Bezier 控制点，避免历史运动轨迹偏移。
- 当前数据模型已有逐对象 `pathType`、Bezier 控制点、`rotationMode`、起止角度。
- 当前运行时旋转已贯通 2D、3D 和离线导出，主要缺口是门板旋转交互、路径编辑效率与多轨迹可视化。

## Requirements (evolving)

- 选择时间轴过渡后进入舞台路径编辑状态。
- 舞台绘制所有前后队形均存在对象的轨迹。
- 默认轨迹也可见：未配置对象显示直线路径；已配置对象显示其实际路径。
- 当前对象轨迹高亮并显示可拖动控制点；其他对象轨迹低对比度显示且不显示控制点。
- 点击舞台上的演员、道具或其轨迹可选中该对象。
- 提供紧凑对象列表，展示对象名称、类型、路径状态和旋转状态，并支持快速切换。
- 对象列表覆盖演员和道具，包括门板。
- 普通道具选中时提供舞台旋转手柄和角度数值输入，两者双向同步。
- 旋转手柄与数值输入更新当前队形角度，并纳入撤销/重做。
- 普通道具可在过渡中沿直线或 Bezier 路径移动，同时从起始角度插值到结束角度。
- 普通道具绕其配置的中心、左侧铰链或右侧铰链旋转。
- 左/右轴道具的几何体从铰链轴点向对应一侧展开，旋转过程中铰链严格沿位置路径移动。
- 每个队形保存逐对象角度；道具进入目标队形后保持目标角度。
- 过渡旋转默认从前一队形角度插值到后一队形角度。
- 高台保持中心旋转，不开放左右铰链模式，避免演员承载关系随旋转轴产生意外位移。
- 门板的旋转结果必须在 2D、3D、实时播放和视频导出中一致。
- 保持现有项目兼容；无自定义运动数据时沿用默认直线移动和静态角度。

- [ ] 当前轨迹明显高亮，Bezier 控制点可直接拖动，其他轨迹保持可辨识但不干扰。
- [ ] 对象列表可区分默认直线、已配置曲线、固定旋转和旋转插值状态。
- [ ] 普通道具可通过舞台旋转手柄和数值输入精确修改当前队形角度。
- [ ] 旋转编辑可撤销和重做，拖动结束后记录一次完整操作。
- [ ] 普通道具在一个过渡内能同时改变位置和角度。
- [ ] 道具到达目标队形后保持该队形保存的角度。
- [ ] 未配置过渡旋转覆盖时，系统自动使用前后队形角度进行插值。
- [ ] 同一道具切换中心、左轴、右轴后，2D 与 3D 中的旋转支点符合预期。
- [ ] 左/右轴模式下，道具旋转时铰链点保持在配置的位置轨迹上。
- [ ] 切换旋转轴模式后，所有队形中的道具几何位置不发生可见跳变。

- [ ] 高台仅使用中心旋转，现有演员站台和抬升行为不受影响。
- [ ] 保存并重开项目后，多对象路径和门板旋转完整恢复。
- [ ] 2D、3D、实时播放和导出在同一时间点得到相同位置与角度。
- [ ] 类型检查、构建和相关回归测试通过。

## Assumptions (temporary)

- “所有对象轨迹”仅在选中过渡时显示，普通队形编辑和播放状态不常显。
- MVP 使用现有直线与三次 Bezier 模型，不加入自由手绘、多段折线或逐点时间控制。
- 轨迹颜色沿用对象颜色，并通过透明度、线宽和虚实区分选中状态。

## Technical Approach

- 将单条 `transitionPath` 视图模型升级为当前过渡的 `transitionPaths[]`，包含对象 ID、对象类型、起终点、路径类型、控制点和选中态。
- 舞台轨迹层统一渲染全部路径，仅给选中对象开放控制点拖动。
- 将对象列表从时间轴大浮层中拆成紧凑路径面板，舞台点击与列表选择共享同一状态。
- 扩展 `Frame`，保存逐对象 `rotations`；静态队形、过渡求值和导出统一读取帧角度。
- 为普通道具增加舞台旋转手柄，使用指针起止 payload 记录角度撤销历史；数值输入复用可清空的草稿输入组件。
- 播放头位于过渡区时，旋转编辑写入目标队形角度，并用当前播放进度即时重新求值预览。
- 继续使用共享场景求值器计算位置和旋转，避免预览与导出分叉。
- 为普通道具持久化旋转轴配置 `center | left | right`，并在 2D DOM、2D 导出 Canvas、3D 实时场景和离线 3D 渲染中使用同一支点换算。

## Out of Scope

- 自由手绘路径。
- 任意数量路径节点或逐节点速度控制。
- 对象碰撞检测和自动避让。
- 路径分组、批量复制或镜像。

## Decision (ADR-lite)

**Context**: 门板等普通道具既需要整体转向，也需要模拟真实开门动作，单一中心旋转无法覆盖两类编舞场景。

**Decision**: 所有普通道具保存旋转轴模式 `center | left | right`，高台固定为 `center`。左右轴按道具自身局部方向定义，而不是舞台全局左右；角度在过渡中与位置同步插值。

**Consequences**: 可表达平移、整体转向和开合动作，且无需新增门板专用模型；同时需要统一修正 2D、3D、Canvas 导出和离线 3D 的 pivot 变换，旧项目缺失该字段时默认 `center`。

**Position semantics**: `center` 模式下位置表示几何中心；`left | right` 模式下位置表示铰链轴点，过渡路径同样描述该轴点的运动。

**Migration on pivot change**: 用户修改旋转轴模式时，系统按道具当前尺寸和各队形角度换算所有帧位置，并换算相关过渡控制点，使道具几何中心和路径形状在视觉上保持不变。

**Rotation persistence**: `Frame.rotations[objectId]` 保存队形角度。旧项目缺失时回退到 `performer.rotation`；过渡默认使用前后帧角度，已有 `ObjectMotion.startRotation/endRotation` 作为显式覆盖继续兼容。

**Transition editing target**: 播放头处于过渡区时，道具旋转手柄和数值输入修改该过渡的目标队形角度；播放画面根据当前时间立即重新插值，不创建独立的临时角度。

## Final Interaction Design

1. 用户点击时间轴中的过渡段。
2. 舞台显示该段所有对象的运动轨迹；对象颜色作为轨迹基础色。
3. 当前对象轨迹使用高亮实线，并显示 Bezier 控制点；其他轨迹使用低透明度细线。
4. 用户可点击舞台对象、轨迹或紧凑对象列表切换编辑对象。
5. 普通道具额外显示旋转轴标记、旋转手柄和数值角度输入。
6. 旋转轴模式为中心、左轴或右轴；左右轴模式下路径代表铰链点。
7. 切换旋转轴时，系统换算所有队形位置和已有路径控制点，保持视觉位置与轨迹不跳变。
8. 在队形区编辑角度时修改当前队形；在过渡区编辑角度时修改目标队形。
9. 播放、2D、3D 和导出统一通过共享场景求值器得到位置与角度。

## Expansion Decisions

- 为未来保留更多路径类型的模型扩展点，但 MVP 仅实现直线与三次 Bezier。
- 路径编辑覆盖演员与所有道具；旋转轴编辑仅覆盖普通道具，高台固定中心轴。
- 本期不做碰撞避让、自由手绘和批量路径操作，避免把核心交互做得过重。
