# 移动端排练显示优化

团员排练只读视图（MobileRehearsal）在人数多时圆点和名字严重重叠，且舞台被顶栏、备注栏和右侧列表挤压。目标：

1. **显示设置**：新增"显示设置"弹层，提供
   - 人物大小缩放（0.5x–2x，只缩放表演者，不动道具/平台）；
   - 名字字体大小缩放（0.6x–2x，基于项目舞台配置的基准字号）；
   - 名字显示/隐藏开关（隐藏后舞台只剩圆点）。
   - 设置持久化到 localStorage（`cosstage.rehearsal-display`），重开排练保留；损坏数据回退默认值。
2. **收起模式重设计**：收起后舞台占满整屏（近全屏），右侧仅保留悬浮竖条：展开按钮 + 上一队形 / 播放 / 下一队形；隐藏顶栏、备注、时钟、进度条与队形列表。Android 返回键在收起态先展开再退出，防误退。
3. **展开布局紧凑化**：顶栏 48px→42px、备注栏上限 23%→15%，舞台在展开态也占大半屏；现有 Playwright 断言（收起后舞台变宽、播放按钮在视口内、360px 竖屏不溢出）必须继续通过。
4. **视角切换**：只读排练默认**演员视角**（台上演员朝向观众，整个平面 180° 点镜像，文字保持正向），顶栏一键切回**导演视角**。实现参考 2D 视频导出的"演员排练视角"（App.tsx Export2DView='rehearsal' 的 x→1-x、y→1-y 镜像语义），在 Stage 组件加 `flippedView` 属性：`rotate(180deg)` 追加在 pan/zoom 变换链尾（保持平移缩放方向自然），米数尺翻到舞台上方，各文字元素用 CSS `rotate` 属性反向。

验证：`mobile/rehearsal-display.ts` 纯函数单测（持久化、钳制、缩放只作用表演者、字号基准回退）；`npm run test:mobile`、`npm run test:mobile:ui`、typecheck、Android 资源同步。

## 实施与验证（2026-10-14）

- `mobile/rehearsal-display.ts`：设置持久化（含演员视角，`cosstage.rehearsal-display`）、逐字段回退与钳制、表演者缩放（道具/平台不动、未设宽深不落 0）、字号叠加（项目未配置时回退 10px 默认）。
- `Stage.tsx` 新增 `flippedView`：`rotate(180deg)` 追加在 pan/zoom 变换链尾（平移缩放方向保持自然）；备场区、主舞台标题、米数尺刻度、舞台前沿、演员名字标签用 Tailwind v4 原生 `rotate` 属性反向，文字全部正向。
- `MobileRehearsal.tsx`：顶栏新增视角切换（默认演员视角）与显示设置；设置弹层含名字开关、人物/字体滑杆与恢复默认；收起态隐藏顶栏/备注/时钟/进度/列表，右侧悬浮胶囊仅留展开+播放+上下切换；Android 返回键收起态先展开防误退；展开布局紧凑化（顶栏 42px、备注上限 15%）。
- 验证：mobile-core 11 通过（新增 3）；mobile-ui 14 通过（排练 4 项含新设置持久化用例）；桌面回归 150 通过；typecheck、生产构建通过；Android 资源同步通过（资产不入库，CI 构建时生成）。
- 视觉验收（Playwright 截图 + 视觉审查）：180° 旋转后全部文字正向、备场区左右正确镜像、收起态胶囊完整居中、弹层控件正常；人物 70%+字体 80% 明显缓解拥挤，隐藏名字彻底消除标签遮挡；360px 竖屏演员视角无溢出。遗留小项：极密簇缩小后仍有部分次级标签重叠（隐藏名字兜底）；竖屏队形卡片"备注"字样截断为既有行为。
