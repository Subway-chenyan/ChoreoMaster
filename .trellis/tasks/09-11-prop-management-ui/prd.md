# 重构道具管理界面

## 目标

- 让道具管理恢复与演员管理一致的分组、拖拽、锁定、显隐和批量操作体验。
- 将道具尺寸、类型、颜色、比例锁和旋转锚点收进独立弹窗，降低侧栏信息密度。
- 将 3D 资产库改为从道具管理点击打开的独立弹窗，保留现有资产创建、导入、搜索、放置和维护能力。

## 需求

- 道具页复用演员页的分组列表结构，并只显示道具分组和道具实例。
- 道具可以创建分组、拖入/移出分组、折叠分组、按分组显隐和锁定。
- 新增道具和编辑道具都使用独立参数弹窗。
- 道具侧栏提供明确的“打开资产库”入口；资产库不再以内嵌双页签形式占据侧栏。
- 道具列表保持紧凑，只呈现名称、道具/高台类型和必要的状态/快捷操作。
- 演员分组右键菜单中的“更改颜色”升级为“批量编辑”，复用单演员编辑弹窗的外观与控件。
- 批量编辑可统一调整组内演员的形状、颜色、尺寸和高度；演员名称保持各自原值。
- 批量编辑跳过已单独锁定的演员，并在没有可编辑演员时禁用入口。

## 验收标准

- [x] 道具页能创建道具分组，并通过拖拽或右键菜单移动道具。
- [x] 新增或编辑道具时，名称、长宽高、颜色、类型、比例锁和旋转锚点可在弹窗中修改。
- [x] 资产库通过道具页按钮以独立弹窗打开；选择资产后进入原有舞台放置流程。
- [x] 演员管理现有行为不回归，道具的锁定、显隐、删除、复制和队形加入/移除仍可用。
- [x] TypeScript 类型检查、相关桌面回归测试和生产构建通过。
- [x] 演员分组右键菜单显示“批量编辑”，打开后呈现与单演员编辑一致的形状、颜色、尺寸、高度和预览区域。
- [x] 保存批量编辑后，组内未锁定演员获得相同外观与尺寸，演员名称不变，分组颜色与所选颜色同步。
- [x] 空分组或仅包含锁定演员的分组不能启动批量编辑。

## 技术方案

- 扩展 `Sidebar` 的现有通用分组列表，使演员和道具两个页签共用一套渲染与分组交互。
- 新增 `PropEditorModal`，集中维护道具实例参数；模型资产版本入口也放入该弹窗。
- 将 `ModelAssetSidebar` 收敛为 portal 渲染的资产库弹窗，移除其“当前项目”实例编辑页。

## 决策

**背景**：当前道具页由资产库/当前项目双页签占满，绕开了演员页已有的分组管理，并把大量参数直接铺在侧栏卡片中。

**决定**：复用通用列表而非复制演员管理代码；资产库与道具参数分别使用独立弹窗。

**影响**：侧栏更轻，分组能力恢复；资产维护和参数编辑多一次明确点击，但获得更充足的编辑空间。

## 范围外

- 不修改道具数据结构、项目文件格式或 3D 资产服务。
- 不重做模型建模器或舞台放置交互。
- 不调整演员参数弹窗的视觉结构。

## 技术备注

- 主要影响 `components/Sidebar.tsx`、`components/model-assets/ModelAssetSidebar.tsx` 和新增道具编辑弹窗。
- 继续使用现有 Electron preload API，不新增 IPC 或主进程能力。
- 演员分组批量编辑扩展 `PerformerEditorModal` 的显示模式，不复制表单实现。
