# 3D 建模器与舞台变换 UI

## 目标

- 让建模器已有的 W/E/R/S 快捷键在界面上可发现，并用一致的图标、中文标签和键帽提示表达当前工具。
- 在 3D 舞台为单选且未锁定的道具提供位移、旋转、缩放控制轴；演员继续沿用现有舞台位移能力。
- 变换过程中暂停轨道相机，播放、资产放置或只读状态下禁用编辑。
- 每次完整手势只产生一次撤销记录；位移写入当前队形，旋转写入当前旋转帧，缩放写入道具实例尺寸。

## 交互设计

- 复用紧凑工具条：观察、位移 W、旋转 E、缩放 R、吸附 S。按钮同时展示图标、动作名称和快捷键键帽。
- 建模器顶部使用工具条；视口内显示当前动作说明和“左键选择 / 拖动彩色轴 / 右键旋转视角 / 滚轮缩放”的常驻轻提示。
- 3D 舞台工具条替换旧的“3D 拖动编辑”开关。观察模式用于相机；位移模式仍支持演员和道具平面拖动；旋转/缩放仅在单选道具时显示控制轴。
- 舞台位移限制在 X/Z 地面平面，旋转限制为 Y 轴，缩放允许 X/Y/Z；吸附分别为网格间距、5 度和 0.1 倍。
- 未选择道具、选择演员、多选、锁定或播放时，工具条给出简短状态提示，不制造无响应控件。

## 验收

- 建模器可通过按钮或 W/E/R/S 切换，控制轴拖动期间相机不抢占输入，松手后可撤销。
- 3D 舞台选中道具后可位移、旋转、缩放，数值在 2D/3D 和属性面板一致，保存重启后保留。
- 锁定、播放和放置资产状态不允许变换；相机控制与对象控制不冲突。
- 类型检查、3D 交互测试、桌面回归测试和生产构建通过。
