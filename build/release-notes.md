# CosStage 1.1.0

建立可审计的桌面版本历史、应用内更新与腾讯云原子发布流程。

- 建立可审计的桌面版本历史、应用内更新与腾讯云原子发布流程。
- 从 1.0.0 覆盖安装 1.1.0 后显示一次迁移与版本更新说明，确认后才标记为已读。
- 播放中暂停时自动切换到当前时间对应的队形，避免继续编辑播放开始时选中的旧队形。
- 更新 Electron 与构建依赖，修复已知的依赖安全问题。
- 3D 预览默认锁定演员和道具拖动，并提供显式拖动编辑开关，避免旋转视角时误改队形位置。
- 在编辑器与产品指南展示当前版本号，并在在线版本记录不可用时显示内置离线更新记录。
- 修复 Windows 发布构建中临时目录长路径与 8.3 短路径表示不同导致的质量门禁误报。

## 迁移说明

1.0.0 用户需要从官网下载 1.1.0 安装包并覆盖安装一次；项目和设置会保留。
