# CosStage 1.4.0

接入 Android 自动构建、固定签名与 COS 发布；网页和 Windows 客户端新增正式 APK 下载入口，预览包与正式包独立发布。

- 接入 Android 自动构建、固定签名与 COS 发布；网页和 Windows 客户端新增正式 APK 下载入口，预览包与正式包独立发布。
- 新增手机团员只读排练模式，仅导入编排和音乐，支持大舞台、队形备注、右侧队形跳转和音乐同步播放。
- 优化手机横屏舞台布局、可收起队形栏和右侧属性面板，新增按米微调与多选快捷操作，修复轻点演员意外触发网格吸附的问题。
- 新增 Android 随身舞台：触屏站位编辑、队形序列、音乐排练、离线自动保存及桌面完整项目包双向互通，并保留原桌面编辑入口。
